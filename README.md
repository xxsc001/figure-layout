# Figure Layout

浏览器中的科研图片排版工具，支持面板字母标注、图片缩放、常用样式、工程文件夹，以及 PNG、TIFF 和 SVG 导出。

## 本地运行

```sh
npm install
npm run dev
```

## 发布

部署说明见 [GITHUB-PAGES.md](GITHUB-PAGES.md)。

工程和原图保存在当前浏览器中；可以在通用设置中选择本地备份目录并恢复备份。切换网址后，需要从本地备份恢复原有工程。
